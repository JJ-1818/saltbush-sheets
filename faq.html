Frequently asked questions

What do I actually get?

A spreadsheet file (.xlsx) and, for some templates, a printable PDF. After you pay, the store emails you a download link straight away.

Do I need Microsoft Excel?

No. Every template works in Google Sheets, which is free. Open Google Drive, choose New > File upload, pick the file, open it and choose File > Save as Google Sheets. Each template's Start Here tab repeats these steps.

Can I use it on my phone?

Yes, in the Google Sheets or Excel app. Bigger screens are easier for setting it up.

Which currency and country?

The $ sign is only a number format, so you can type any currency. Templates with tax features say which country they're set up for (for example, the GST tracker is for Australia).

Is anything here financial, tax or legal advice?

No. These are tools to organise your own numbers. For advice about your situation, talk to a qualified professional.

Can I share or resell the file?

Please don't. Each purchase is for use in your own household or business. See the terms.

Something's not working

Email [your business email] with the template name and what's happening. We'll help, fix it or replace it. See refunds.
